# Хроники мира

Гибридная настольная/цифровая стратегическая игра на 2–6 игроков.

## Концепция

- Общий живой мир выводится на TV/проектор.
- Каждый игрок управляет королевством со смартфона.
- Сервер является единым источником истины.
- Мир процедурно генерируется по World Seed.
- Hex-сетка является логической основой территории, но визуально мир должен восприниматься как цельный ландшафт.
- Ключевой приоритет разработки — качество карты, атмосфера, читаемость и эффект присутствия.

## Текущий этап — v0.1

Заложен фундамент рендера мира:

- TypeScript + Vite
- Three.js для TV-клиента
- общая модель WorldHex
- детерминированный генератор мира
- базовые типы ландшафта: равнина, лес, горы, вода, пустыня
- подготовлена структура для дальнейших рек, дорог, поселений, ресурсов, границ и тумана войны

## Архитектура

```text
client/
  tv/          общий экран мира
  player/      приватный интерфейс игрока
server/        игровая логика и синхронизация
shared/        общие типы и протоколы
world/         генерация и симуляция мира
docs/          правила и техническая документация
```

## Ближайшие этапы

1. Улучшить генерацию географии: связные высоты, берега и биомы.
2. Сделать реальные реки, лесные массивы и горные цепи.
3. Добавить дороги и поселения, завязанные на географию.
4. Добавить тонкие границы hex-территорий без ощущения шахматной сетки.
5. Добавить fog of war и состояние discovered.
6. Подключить сезоны и визуальные изменения мира.
7. После фундамента карты — сервер состояния игры и месячный цикл.
8. Затем — телефонный интерфейс игрока и синхронизация TV/смартфонов.

## Важный принцип

Сначала строится правильный фундамент мира и рендера. Экономика, дипломатия, войны и события подключаются к единому состоянию мира, а не создают собственные независимые версии карты.
